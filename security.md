# Security Policy

## Supported Versions

Please check the project for any specific supported versions. Currently, this project is in active development, and we recommend using the latest commit on the `main` branch.

## Reporting a Vulnerability

If you discover a security vulnerability within LandLordLens, please do not disclose it publicly.

Instead, please send an email to the project maintainers or open a private security advisory on GitHub if applicable. We take all security vulnerabilities seriously and will work to resolve them as quickly as possible.

When reporting an issue, please include:

- A detailed description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.
- Any suggested mitigations (if you have them).

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress.
